# Tasks: Add Tailwind CSS to Vite React Project

1. Install Tailwind CSS and Vite plugin:
   - `npm install tailwindcss @tailwindcss/vite`
2. Update `vite.config.js` to add the Tailwind plugin.
3. Add `@import "tailwindcss";` to the top of `src/index.css`.
4. (Optional) Create a `tailwind.config.js` for custom configuration.
5. Add a sample Tailwind class to a component (e.g., `<h1 className="text-3xl font-bold underline">Hello world!</h1>`).
6. Verify that Tailwind utilities work by running `npm run dev` and checking the UI.
