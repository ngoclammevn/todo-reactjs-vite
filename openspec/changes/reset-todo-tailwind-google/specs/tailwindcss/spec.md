## ADDED Requirements

### Requirement: Tích hợp TailwindCSS
Dự án Todo apps được tích hợp TailwindCSS đầy đủ, có thể sử dụng class tailwind trong component React.
#### Scenario:
- Cài đặt tailwindcss, postcss, autoprefixer.
- Tạo file cấu hình tailwind.config.js, postcss.config.js.
- Import tailwind vào index.css.
- Kiểm tra class tailwind hoạt động trên UI.
