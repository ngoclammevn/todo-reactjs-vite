# Đề xuất: reset css, component và tạo mới Todo app với TailwindCSS, Lucide icon, giao diện giống Google

## Mục tiêu
- Reset toàn bộ mã nguồn hiện tại (src/, public/, css) về trạng thái khởi đầu sạch.
- Thiết lập lại cấu trúc dự án Todo app sử dụng TailwindCSS, Lucide icon.
- Thiết kế UI theo phong cách Google (Material-like, đơn giản, hiện đại).
- Đảm bảo mọi thay đổi tuân thủ openspec conventions, có spec, task, và reasoning rõ ràng.

## Phạm vi
- Xóa hoặc thay thế toàn bộ code hiện tại liên quan đến demo Vite/React.
- Thiết lập lại cấu trúc component Todo app.
- Tích hợp TailwindCSS, Lucide icon.
- Đảm bảo khả năng mở rộng, maintainable, dễ kiểm thử.

## Lý do
- Đáp ứng yêu cầu UI/UX mới, chuẩn hóa codebase, loại bỏ legacy code không liên quan.
- Đảm bảo nền tảng tốt cho các tính năng Todo nâng cao về sau.
