## Requirements
### Requirement: Add Todo
The system SHALL allow the user to enter text and add a new todo item to the list.
#### Scenario:
- User enters text in the input field and clicks the add button. The new todo appears in the list.

### Requirement: View Todos
The system SHALL display a list of all current todo items to the user.
#### Scenario:
- User opens the app and sees all current todos listed.

### Requirement: Complete Todo
The system SHALL allow the user to mark a todo as completed, and completed todos SHALL be visually distinct from incomplete ones.
#### Scenario:
- User clicks a checkbox or button to mark a todo as completed. The todo's appearance changes to indicate completion.

### Requirement: Remove Todo
The system SHALL allow the user to remove a todo item from the list.
#### Scenario:
- User clicks a remove button on a todo item. The item is removed from the list.
